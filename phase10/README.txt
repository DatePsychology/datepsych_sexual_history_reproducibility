Phase 10 supplementary robustness and synthesis audit

thomas_robustness.py: run with Python, numpy, pandas, scipy, statsmodels. Place phase10 folder beside original b4e8u-osfstorage-archive.zip. Reads Study 3 only; averages matched frequency-profile differences (rating at 4 minus rating at 36 partners) within participants, allowing 1+, 12+, or all 15 matched pairs. HC3 OLS/WLS sex contrasts, country controls; equal country-by-sex cell weights exclude OTH; exploratory equivalence margins 0.25 and 0.5 rating points. All estimates observational sex contrasts on ratings, not causal sex effects. Order is not randomized within this contrast, as in original stimulus sequence. These are exploratory follow-up tests, not a preregistration. No raw respondent data included.
nsfg_reexecution.txt and nsfg_interactions.txt: aggregate console results from rerunning the previously supplied nsfg_phase3_code.zip against CDC.zip, using combined survey weights and Taylor variance. Full input and microdata are not included. See README in phase 3 package for execution.
